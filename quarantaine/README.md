# QUARANTAINE

Jeu de survie zombie en HTML5 Canvas, jouable au clavier/souris (PC) ou au tactile (mobile).

Une infection a ravagé la ville. Seul, armé d'un pistolet et d'un vieux feu de camp,
survivez jour après jour. Au bout du 2ème jour, un portail mystérieux s'ouvre — ce qui
se cache derrière décidera de votre destin.

## Fonctionnalités

- Cycle jour / nuit avec vagues de zombies (walker, runner, brute, boss)
- Base fortifiée à améliorer (feu de camp, murs circulaires)
- Fouille de maisons pour récolter bois, métal, argent et nourriture
- Craft de murs, armurerie persistante (armes conservées après la mort)
- Donjon / labo avec boss gardien, clé, portail final et boss final
- Contrôles doubles : deux sticks virtuels sur mobile, WASD + souris sur PC

## Jouer

Ouvrez simplement `index.html` dans un navigateur — tout est autonome dans un seul fichier
(HTML + CSS + JavaScript, aucune dépendance à installer).

## Contrôles

- **Stick gauche** : se déplacer
- **Stick droit** : viser & tirer
- **Bouton central** : interagir (fouiller, améliorer, entrer dans un portail…)
- **Clavier** : WASD pour se déplacer, souris pour viser et tirer
